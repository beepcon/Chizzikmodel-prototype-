================================================================
  라이카 - AI 버튜버   사용법
================================================================

치지직 채팅, 내 목소리, 게임 화면에 반응해서 말하는 AI 버튜버입니다.
설정은 전부 프로그램 안에서 합니다.


----------------------------------------------------------------
1. 준비물
----------------------------------------------------------------

프로그램과 별개로 아래가 필요합니다.

  [1] Anthropic API 키        - 대사 생성
      console.anthropic.com 에서 발급

  [2] GPT-SoVITS 통합패키지    - 목소리 합성
      github.com/RVC-Boss/GPT-SoVITS 의 Releases 에서
      windows 7z package 를 받아 압축 해제

  [3] VB-CABLE                - 목소리를 아바타로 전달
      vb-audio.com/Cable  (설치 후 재부팅 필요)

  [4] VTube Studio            - 아바타
      Steam 에서 무료

  [5] 참조 음성용 녹음         - 흉내 낼 목소리
      긴 녹음이어도 됩니다. 프로그램이 알아서 구간을 잘라줍니다.
      (설정 - 음성 탭의 "긴 녹음에서 참조 음성 만들기")

  NVIDIA 그래픽카드가 있어야 원활합니다.
  없으면 음성 인식이 CPU 로 돌아가 느려집니다.


----------------------------------------------------------------
2. 처음 설정
----------------------------------------------------------------

  받은 파일들은 라이카가 들어있는 폴더 안에 두세요.
  프로그램이 알아서 찾아 경로를 잡아줍니다.

    라이카 폴더\
      +- 라이카.exe
      +- GPT-SoVITS-v2pro-...\    <- 여기에 압축 해제
      +- refs\                    <- 참조 음성용 녹음
      +- 사용법.txt

  프로그램 오른쪽 아래 [준비물 점검] 을 누르면
  무엇이 있고 무엇이 없는지, 어디서 받는지 알려줍니다.

  1) VB-CABLE 설치 후 재부팅

  2) VTube Studio 실행
     - 설정에서 마이크를 "CABLE Output" 으로 지정
     - 모델 설정에서 입 파라미터의 Input 을
       "Voice Volume" 계열로 변경

       * 중요 *
       Input 이 "MouthOpen" 으로 되어 있으면 입이 움직이지 않습니다.
       MouthOpen 은 웹캠 얼굴 추적용이라 오디오 립싱크가 반영되지
       않습니다. 반드시 Voice Volume 계열로 바꾸세요.
       Smoothing 값도 낮춰야 반응이 보입니다.

  3) 라이카 실행 후 [준비물 점검] 으로 상태 확인
     GPT-SoVITS 를 폴더 안에 풀어두었다면
     [이 경로 적용] 을 누르면 경로가 자동으로 들어갑니다.

  4) 오른쪽 아래 [설정] 클릭

     - 간단 탭  (설정을 열면 여기가 먼저 보입니다)
         자주 쓰는 것만 모아 두었습니다.
         API 키 / 치지직 채널 ID / 글자 수 한도 /
         말을 빨리 시작하기 / 마이크 문턱값 /
         내 스피커로도 듣기 / 표정 사용
         여기서 고친 값은 아래 탭들에도 그대로 반영됩니다.

     - 연결 탭
         Anthropic API 키
         GPT-SoVITS 폴더   (api_v2.py 가 들어있는 폴더)
         치지직 채널 ID     (채널 주소 뒤에 붙는 문자열)

     - 음성 탭
         [긴 녹음에서 참조 음성 만들기] 를 누르면
         긴 음성 파일에서 쓸 만한 구간을 찾아 목록으로 보여줍니다.
         [듣기] 로 확인하고 [사용] 을 누르면
         파일과 대사가 자동으로 채워집니다.

         이미 3~10초짜리 참조 음성이 있다면
         직접 파일과 대사를 입력해도 됩니다.

     - 성격 탭
         말투와 성격 설정

  5) [저장] 누르고 [방송 시작]


----------------------------------------------------------------
3. 사용법
----------------------------------------------------------------

  [방송 시작]      음성 서버를 켜고 파이프라인을 시작합니다
                   처음 시작할 때 모델 로딩에 1~2분 걸립니다

  [마이크] 또는 F8  내 목소리 입력을 켜고 끕니다 (기본 꺼짐)

  [화면 보기]       일정 간격으로 화면을 보고 실황합니다
                    설정 - 인식/화면 탭에서 무엇을 볼지 고를 수 있습니다.
                      모니터 전체 / 특정 창 / 지정 영역

  입력창            라이카에게 직접 말 걸기
                    "닉네임: 내용" 으로 치면 시청자 채팅처럼 들어갑니다


----------------------------------------------------------------
4. 주의사항
----------------------------------------------------------------

  - 음성 데이터는 이용 권리가 있는 것만 쓰세요.
    방송이나 성우 음원을 무단으로 학습하면 문제가 됩니다.
    본인 목소리, 또는 AI 이용이 허가된 공개 데이터를 쓰세요.

  - API 키는 config.json 에 저장됩니다.
    이 파일을 다른 사람에게 주거나 인터넷에 올리지 마세요.
    대화 기록이 담긴 sessions 폴더,
    마이크 녹음이 담긴 debug_audio 폴더도 마찬가지입니다.


----------------------------------------------------------------
부록. 문제가 있다면 다음과 같이 해 보세요
----------------------------------------------------------------

  [ 입이 안 움직입니다 ]
    VTube Studio 모델 설정에서 입 파라미터의 Input 이
    "Voice Volume" 계열인지 확인하세요.
    MouthOpen 으로 두면 오디오 립싱크가 반영되지 않습니다.
    Smoothing 값도 낮추세요.

  [ 소리는 나는데 목소리가 뭉개집니다 ]
    참조 음성이 3~10초인지 확인하세요.
    "참조 음성의 대사"가 실제 내용과 정확히 같아야 합니다.
    대사가 틀리면 발음이 무너집니다.
    [긴 녹음에서 참조 음성 만들기] 를 쓰면
    길이와 대사를 자동으로 맞춰줍니다.

  [ 참조 음성 구간을 못 찾습니다 ]
    한 문장을 3초 이상 이어서 또렷하게 말한 구간이 있어야 합니다.
    말이 짧게 끊기거나 배경음이 크면 후보가 나오지 않습니다.

  [ 음성 인식이 안 됩니다 ]
    설정 - 간단 탭의 "마이크 문턱값" 을 조절하세요.
    말해도 안 잡히면 낮추고,
    가만히 있는데 인식되면 높입니다.
    처음에는 0.02 로 두고 쓰면 됩니다.

  [ 아무 말도 안 했는데 혼자 알아듣습니다 ]
    설정 - 간단 탭의 "마이크 문턱값" 을 올리세요.
    그래도 계속되면 주변 소음을 줄여 보세요.

  [ 말이 중간에 끊깁니다 ]
    목소리를 만드는 프로그램이 멈춘 것입니다.
    라이카가 알아서 다시 켜고, 돌아오면
    "죄송해요, 잠깐 목이 막혔어요" 라고 먼저 말합니다.
    그래도 안 되면 화면에 "껐다 켜 주세요" 라고 안내가 뜹니다.
    그때는 라이카를 껐다 켜면 됩니다.

  [ 말을 늦게 시작합니다 ]
    설정 - 간단 탭의 "말을 빨리 시작하기" 를 켜세요.
    문장을 다 만들기 전에 앞부분부터 말하기 시작합니다.

  [ F8 이 게임 안에서 안 먹습니다 ]
    게임이 관리자 권한으로 실행 중이면 전역 단축키가 막힙니다.
    창의 마이크 버튼을 쓰거나,
    라이카를 관리자 권한으로 실행하세요.

  [ 목소리가 내 스피커로 안 들립니다 ]
    설정 - 간단 탭의 "내 스피커로도 듣기" 를 켜세요.

  [ 화면을 봐도 검은 화면만 보인다고 합니다 ]
    게임이 전체화면 전용 모드이면 캡처가 되지 않습니다.
    테두리 없는 창 모드(Borderless)로 바꾸세요.

  [ 특정 창을 골랐는데 못 찾는다고 합니다 ]
    창을 껐다 켜면 제목으로 다시 찾습니다.
    제목이 바뀌는 프로그램이라면 목록 새로고침 후 다시 고르세요.

  [ 방송 시작이 안 되고 경고창이 뜹니다 ]
    창에 적힌 항목을 설정에서 채우면 됩니다.

  [ 같은 문제가 자꾸 생깁니다 ]
    방송 중 화면에 떴던 글이 폴더의 laika.log 에 그대로 남습니다.
    이 파일을 열어 보면 언제 무엇이 잘못됐는지 알 수 있습니다.

  [ 이름이나 단어를 이상하게 읽습니다 ]
    폴더 안의 tts_dict.json 을 메모장으로 열어
    "어떻게 읽어야 하는지" 를 한 줄 적으면 됩니다.
    프로그램은 다시 켜지 않아도 됩니다.

    예) 내 이름 "우앙4시" 를 "우앙 사시" 라고 읽는다면

        "고유명사": {
          "우앙4시": "우앙 네시"
        }

    적는 곳은 셋 중 하나를 고르면 됩니다.

        약어      LP, ATK 처럼 글자를 풀어 읽어야 하는 것
        고유명사   사람 이름, 채널 이름, 작품 이름
        영단어     보통 영어 단어

    왼쪽에 나오는 글자, 오른쪽에 들리고 싶은 소리를 적습니다.
    큰따옴표와 쉼표를 빠뜨리지 않게 조심하세요.
