# 라이카 (Laika)

치지직 채팅과 호스트의 음성, 게임 화면에 반응해 말하는 AI 버튜버입니다.
파인튜닝한 목소리로 발화하고 Live2D 아바타의 입이 따라 움직입니다.

개인 프로젝트이며, 방송 채널은 공개하지 않습니다.

## 받는 법

깃을 몰라도 받을 수 있습니다.

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼을 누릅니다.
2. 맨 아래 **`Download ZIP`** 을 누릅니다.
3. 받은 zip 파일을 원하는 곳에 압축 해제합니다.

깃이 깔려 있다면 이 한 줄로도 됩니다.

```
git clone https://github.com/beepcon/Chizzikmodel-prototype-.git
```

## 실행하는 법

압축을 푼 폴더에서 아래 순서대로 하면 됩니다.

**1) 파이썬 설치** — [python.org](https://www.python.org/downloads/) 에서 받습니다.
설치 화면 맨 아래의 **`Add python.exe to PATH`** 를 반드시 체크하세요.

**2) 필요한 패키지 설치** — 폴더 주소창에 `cmd` 를 치고 엔터를 누른 뒤,
검은 창에 아래를 붙여 넣습니다. 몇 분 걸립니다.

```
pip install -r requirements.txt
```

**3) 실행** — 폴더 안의 **`바로실행.bat`** 을 더블클릭합니다.
명령으로 켜려면 `python laika_gui.py` 입니다.

**4) 나머지 준비물** — 처음 켜면 아무것도 설정돼 있지 않습니다.
창 오른쪽 아래의 **`준비물 점검`** 을 누르면 무엇이 없는지,
어디서 받는지 알려줍니다.
API 키, 목소리 합성기, 아바타 설정은 같은 폴더의
**`사용법.txt`** 에 처음부터 끝까지 적혀 있습니다.

바탕화면 아이콘으로 쓰고 싶으면 `EXE만들기.bat` 을 실행해
exe 로 만들 수 있습니다. (파이썬과 패키지 설치는 먼저 끝나 있어야 합니다)

> 윈도우에서 NVIDIA 그래픽카드가 있는 환경을 기준으로 만들었습니다.
> 그래픽카드가 없으면 음성 인식이 느려집니다.

## 구조

```
치지직 채팅 ─────┐
호스트 음성(STT) ─┼─→ 큐 ─→ Claude API ─→ GPT-SoVITS ─→ VB-Cable ─→ VTube Studio
게임 화면(Vision)─┤   (우선순위)                (로컬)              (립싱크)
콘솔 입력 ───────┘                                    └─→ 스피커 (모니터링)
```

| 구성 | 사용 기술 |
|---|---|
| 채팅 수집 | chzzkpy (웹소켓), 끊기면 5초 간격 자동 재접속 |
| 음성 인식 | faster-whisper (medium), CUDA / CPU 자동 폴백 |
| 응답 생성 | Claude API, 최근 20턴 유지 |
| 화면 인식 | mss 캡처 → 리사이즈 → Claude vision |
| 음성 합성 | GPT-SoVITS v2Pro 파인튜닝 모델, 로컬 HTTP 서버 |
| 아바타 | VB-Audio Virtual Cable → VTube Studio |
| GUI | CustomTkinter |

### 파일 구성

| 파일 | 역할 |
|---|---|
| `laika_gui.py` | 화면. 설정, 준비물 점검, 참조 음성 추출 창 포함 |
| `laika_core.py` | 파이프라인. 큐 관리, 응답 생성, 음성 합성, 재생 |
| `laika_setup.py` | 준비물 탐색 및 상태 점검 |
| `laika_refmaker.py` | 긴 녹음에서 참조 음성 구간 추출 |
| `build_exe.py` | PyInstaller 빌드 |

UI 와 파이프라인을 분리했습니다. 코어의 콜백은 워커 스레드에서 오므로
큐를 거쳐 Tk 타이머에서만 위젯을 갱신합니다.

## 설계에서 신경 쓴 것

**큐 우선순위** — 호스트 발언은 전부 처리하고, 시청자 채팅은 최신 우선으로
쌓인 것을 버립니다. 방송에서 모든 채팅에 답하는 것은 애초에 불가능하고,
오래된 채팅에 뒤늦게 답하는 쪽이 더 어색하기 때문입니다.
채팅이 몰리면 최근 몇 개를 묶어 한 번에 반응합니다.

**응답 지연** — 답변 전체를 합성하고 재생하면 첫 소리까지 오래 걸립니다.
문장 단위로 쪼개어 첫 문장을 재생하는 동안 다음 문장을 합성합니다.

**에코 차단** — 스피커로 나간 목소리를 마이크가 되받으면 자기 말에 자기가
대답하는 순환이 생깁니다. 재생 중에는 마이크 입력을 버립니다.

**끊기지 않기** — 응답 하나가 실패해도 방송이 멈추면 안 됩니다.
워커의 예외를 흡수하고, 웹소켓 리스너는 어떤 경우에도 반환하지 않습니다.
(반환되면 `asyncio.gather` 가 워커까지 정리해 전체가 멈춥니다)

**환경 차이** — CUDA DLL 경로는 설치 위치가 제각각이라 고정하면 깨집니다.
site-packages 를 훑어 찾아내고, 실패하면 CPU 로 넘어갑니다.
오디오 장치도 번호 대신 이름으로 찾습니다.

## 개발 노트

작업하며 실제로 막혔던 것들입니다.

- Whisper 의 구간 타임스탬프는 앞뒤 침묵을 포함하는 경우가 많습니다.
  6.6초로 잡힌 구간의 실제 발화가 2.1초여서 참조 음성이 무너졌습니다.
  에너지 기준으로 잘라낸 뒤 실제 발화 길이로 판정해야 합니다.
- 참조 음성의 대사가 실제 내용과 다르면 발음이 통째로 뭉개집니다.
  잘라낸 파일을 다시 전사해 대사를 확정하는 편이 안전합니다.
- 96kHz 원본을 그대로 참조로 넣으면 피치가 틀어집니다. 32kHz 로 통일합니다.
- 학습 UI 의 "완료" 표시는 프로세스가 종료되면 성공 여부와 무관하게 뜹니다.
  가중치 파일의 존재로 판정해야 합니다.
- `torch.cuda.OutOfMemoryError` 가 "free 18GB" 와 함께 나오면 VRAM 이 아니라
  시스템 RAM 커밋 한계나 남아 있는 좀비 프로세스를 의심해야 합니다.
- `OMP: Error #15` 는 `KMP_DUPLICATE_LIB_OK=TRUE` 로 우회합니다.
  자식 프로세스를 띄우는 구조라면 부모가 아니라 자식의 환경에 넣어야 합니다.
- `os.add_dll_directory` 를 무시하는 로더가 있습니다. PATH 앞에도 넣고,
  DLL 등록은 해당 라이브러리를 import 하기 전에 끝내야 합니다.
- chzzkpy 2.x 부터 비공식 API 는 `chzzkpy.unofficial.chat` 으로 옮겨졌고,
  `ahttp-client` 는 2.0.0 에서 `extension` 모듈이 사라져 1.1.0 으로 고정해야 합니다.
- VTube Studio 에서 오디오 립싱크를 쓰려면 입 파라미터의 입력을
  `Voice Volume` 계열로 바꿔야 합니다. `MouthOpen` 은 얼굴 추적용이라
  마이크 신호가 아무리 정상이어도 반영되지 않습니다.
- uvicorn 서버는 `terminate()` 를 무시하고 버티는 경우가 있어
  프로세스 트리째 강제 종료가 필요합니다.

## 음성 데이터에 관하여

이 저장소에는 음성 모델과 참조 음성이 포함되어 있지 않습니다.
용량 문제도 있지만, 음성은 권리 관계가 걸리는 자료이기 때문입니다.

사용하실 때는 **이용 권리가 확인된 음성만** 쓰시기 바랍니다.

- 본인 목소리 녹음
- AI 학습·합성 이용이 명시적으로 허가된 공개 데이터셋
  (AI Hub 음성합성 데이터, つくよみちゃんコーパス 등)

방송 녹화, 성우 음원, 상업 콘텐츠에서 추출한 음성을 무단으로 학습하는 것은
음성권과 저작권 문제가 됩니다. 여러 화자를 섞더라도 특정 인물이 식별될
정도라면 마찬가지입니다.
